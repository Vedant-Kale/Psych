# Free student programmes and resources for a portfolio website with an AI feature (Master's student, Australia), researched 2026-11-24

Scope note: offer details come from official pages fetched on 2026-11-24 unless marked otherwise. Items marked **UNVERIFIED** come from search-result summaries, third-party pages, or prior knowledge, and were not confirmed on an official page in this session.

**Biggest change since 2025:** GitHub Models, previously the obvious free inference API for students, was **fully retired on 2026-07-30**. Do not plan around it.

## Overview: programme-by-programme facts (what, eligibility, verification, duration, card, restrictions)

### Takeaway
For an Australian Master's student, the most useful free set is: the GitHub Student Developer Pack (free domains, Heroku credit, Copilot Student, Codespaces, Pages), Azure for Students ($100 credit, no card), and the Gemini API free tier for AI. AWS Educate gives no credits. Google Cloud credits come only through faculty. GitHub Models is gone.

### Cited Findings

Other proof of current enrolment is also accepted, such as a student ID or enrolment letter. — [GitHub Docs: applying](https://help.github.com/articles/applying-for-a-student-developer-pack); [Student Pack FAQ discussion](https://github.com/orgs/community/discussions/111352) (search summary; the exact list of accepted documents was not checked)

  - Name.com: one free domain from 25+ extensions (e.g. .app, .dev, .studio). The Name.com account needs a unique address, or the request may be treated as a duplicate. The page states no duration. — [GitHub Student Pack](https://education.github.com/pack)
  - .TECH: "One standard .TECH domain free for 1 year." — [GitHub Student Pack](https://education.github.com/pack)
- Hosting and cloud:
  - GitHub Pages: one user site plus unlimited project sites. This is a general GitHub feature, not student-only. — [GitHub Student Pack](https://education.github.com/pack)
  - Heroku: US$13 credit per month for 24 months. — [GitHub Student Pack](https://education.github.com/pack)
  - Microsoft Azure: free access to 25+ services plus a $100 credit, for ages 18+. A separate offer covers ages 13 to 17. — [GitHub Student Pack](https://education.github.com/pack)
  - Microsoft Visual Studio Dev Essentials: 1 year of Azure services with a $200 credit for the first month. — [GitHub Student Pack](https://education.github.com/pack)
  - Appwrite: Education plan for 6 months (2 projects at Pro-level limits, about $40/month value). — [GitHub Student Pack](https://education.github.com/pack)
  - MongoDB: $50 in Atlas credits. — [GitHub Student Pack](https://education.github.com/pack)
  - The fetched pack page does **not** list DigitalOcean, Cloudflare, Vercel or Netlify. A DigitalOcean credit appeared in earlier years; on the 2026-11-24 fetch it no longer appears. — [GitHub Student Pack](https://education.github.com/pack)
- Tools useful for a portfolio:
  - GitHub Pro: free while a student.
  - GitHub Codespaces: Pro-level access.
  - JetBrains: free student subscription, renewed annually.
  - Clerk: Pro plan free while a student.

  - SimpleAnalytics: Starter plan free for 1 year (100k page views per month).
  - Doppler: Team plan free while a student.
  - Bootstrap Studio: free licence while a student.

  - Notion: Education plan with extra AI responses.
  - Icons8: 3 months. IconScout: 1 year.
  - Source for all of the above: [GitHub Student Pack](https://education.github.com/pack)
- AI:
  - GitHub Copilot Student: available to verified students. It includes unlimited code completions and an allowance of "GitHub AI Credits" (amount not stated). Chat and agent use is limited to models picked by auto model selection. — [GitHub Student Pack](https://education.github.com/pack)
  - Copilot Student is a separate plan, "not the full feature set of Copilot Pro". This comes from a search summary of community FAQs and is **UNVERIFIED** on an official page. — [Community discussion #111352](https://github.com/orgs/community/discussions/111352)
  - Copilot is a coding assistant. It is not an inference API that a deployed website can call.
- Card required: the pack page states no card requirement for the pack itself. Individual partners may ask for a card. Not checked per partner.
- When student status ends: many offers are worded "while you're a student" (GitHub Pro, Termius, Doppler, Clerk, Bootstrap Studio). Fixed-term offers such as Namecheap 1 yr, .TECH 1 yr and Heroku 24 months run for their stated term. — [GitHub Student Pack](https://education.github.com/pack)

**GitHub Models (free inference API): RETIRED**
- GitHub Models was closed to new customers from 2026-06-16. It was fully retired on 2026-07-30. The playground, model catalog, inference API and BYOK "are no longer available to any customer". GitHub points users to Azure AI Foundry instead. — [GitHub changelog 2026-07-01](https://github.blog/changelog/2026-07-01-github-models-is-being-fully-retired-on-july-30-2026); [GitHub changelog 2026-06-16](https://github.blog/changelog/2026-06-16-github-models-is-no-longer-available-to-new-customers); [GitHub Docs](https://docs.github.com/en/github-models/use-github-models/prototyping-with-ai-models)

**Microsoft Azure for Students** (azure.microsoft.com/free/students and the Learn FAQ, fetched 2026-11-24; FAQ updated 2026-08-03)
- What it gives:
  - "$100 credit to use on Azure services within 12 months".
  - 20+ popular services free for 12 months and 65+ always-free services.
  - "No credit card required".
  - One account per person.
  - Source: [Azure for Students](https://azure.microsoft.com/en-us/free/students)
- Eligibility:
  - You must affirm that you are a **full-time** student at an accredited, degree-granting university.
  - You verify through your organisation's email address.
  - MOOCs and for-profit trainings are not eligible.
  - The GitHub pack page lists this offer as 18+.
  - Sources: [Azure Education Hub FAQ](https://learn.microsoft.com/en-us/azure/education-hub/azure-dev-tools-teaching/program-faq); [GitHub Student Pack](https://education.github.com/pack)
  - **Australian note:** a part-time Master's student does not meet the "full-time" affirmation.
- Duration and renewal:
  - Renew yearly by signing up again while still a student.
  - If you do not upgrade when the credit or 12 months runs out (whichever comes first), deployed products are decommissioned.
  - You have 90 days to upgrade to pay-as-you-go.
  - Source: [Azure Education Hub FAQ](https://learn.microsoft.com/en-us/azure/education-hub/azure-dev-tools-teaching/program-faq)
- Use restriction: the FAQ answer to "production or only development?" says access is "expressly for the support of education or teaching, noncommercial research, or efforts to design, develop, test, and demonstrate software applications for these purposes." The credit cannot be used on Marketplace offers. — [Azure Education Hub FAQ](https://learn.microsoft.com/en-us/azure/education-hub/azure-dev-tools-teaching/program-faq)
- Static Web Apps: always free, with "100 GB bandwidth per subscription, 2 custom domains, and 0.5 GB storage per app". — [Azure for Students](https://azure.microsoft.com/en-us/free/students)
- Other always-free services:
  - Functions: 1M requests.
  - Cosmos DB: 1,000 RU/s and 25 GB.
  - SQL DB serverless: 100,000 vCore-seconds per month.
  - AI Search: 50 MB.
  - Content Safety: 5,000 records.
  - Speech: 0.5M neural characters per month.
  - Translator: 2M characters.
  - Source: [Azure for Students](https://azure.microsoft.com/en-us/free/students)
- Azure OpenAI / Microsoft Foundry:
  - The students page lists Azure OpenAI ("o1 and GPT-4 series") and Microsoft Foundry as available. It lists **no free quota** for either, so usage would draw from the $100 credit. — [Azure for Students](https://azure.microsoft.com/en-us/free/students)
  - Community Q&A (2024 to 2026, not official policy) reports problems on student subscriptions:
    - zero or tight model quota;
    - quota increases rejected;
    - deployment limited to 5 allowed regions by policy;
    - newer models needing a pay-as-you-go upgrade.
  - **UNVERIFIED** — sources: [MS Q&A 2183197](https://learn.microsoft.com/en-us/answers/questions/2183197/azure-openai-with-azure-for-students); [MS Q&A quota](https://learn.microsoft.com/en-ie/answers/questions/2224916/azure-ai-foundry-quota-insufficient-issues-student); [MS Q&A student foundry issue](https://learn.microsoft.com/en-us/answers/questions/5823985/azure-student-foundry-issue)
  - Community posts from 2026 report "Not eligible" errors for Azure for Students even with an approved GitHub pack. Microsoft applies its own criteria. **UNVERIFIED** — [MS Q&A 5854223](https://learn.microsoft.com/en-us/answers/questions/5854223/cannot-activate-azure-for-students-eligibility-err)
- Azure for Students Starter:
  - Free tier of App Service, Functions, Notification Hubs, MySQL, App Insights and DevOps.
  - No card, no time limit.
  - Ages 16+ outside the US.
  - Verify by school email or Shibboleth.
  - Source: [Azure Education Hub FAQ](https://learn.microsoft.com/en-us/azure/education-hub/azure-dev-tools-teaching/program-faq)

**AWS Educate** (fetched 2026-11-24)
- Free hands-on labs and learning content.
- "No credit card needed".
- Open to anyone aged 13+ with just an email address.
- The page mentions **no cloud credits** and gives no lab duration.
- Source: [AWS Educate](https://aws.amazon.com/education/awseducate/)
- AWS Academy is institution-run (course labs through the university). Not researched; see Gaps.

**Google Cloud education credits**
- Faculty at eligible institutions apply for credits: up to $100 per teaching staff member and up to $50 per student. Students cannot apply themselves.
- Students redeem a coupon URL from faculty, using a school-domain email.
- No credit card required. A card prompt means you are on the Free Trial instead.
- Credits are valid 1 year after redemption.
- Sources: [Google Cloud edu credits help](https://support.google.com/google-cloud-higher-ed/answer/10322773?hl=en); [Get and redeem education credits](https://docs.cloud.google.com/billing/docs/how-to/edu-grants); [Teaching credits](https://edu.google.com/intl/ALL_us/programs/credits/teaching/); [Terms](https://support.google.com/google-cloud-higher-ed/answer/11448439)
- A 2016 blog post restricted this to US faculty. Current docs do not repeat that restriction, so Australian eligibility is unconfirmed. — [Google Cloud blog 2016](https://cloud.google.com/blog/products/gcp/new-google-cloud-platform-education-grants-offer-free-credits-to-students)

**Google AI student plan (Gemini app — consumer chat, not an API)**
- Announced 2026-08-19.
- Students outside the US get **1 year of Google AI Plus** free (140+ markets; Australia not excluded). US students get AI Pro.
- Redeem by **31 Dec 2026** at one.google.com/ai-student.
- A **valid payment method is required**. After the year it auto-charges AI Plus at US$4.99 per month or the local equivalent, unless cancelled.
- Source: [Google blog 2026-08-19](https://blog.google/innovation-and-ai/products/gemini-app/student-offer-google-ai/)
- The AI Pro student trial is now US-only. Australians who claimed the earlier (Oct 2025) AI Pro offer keep it until their eligibility ends. — [Google support: AI Pro student trial](https://support.google.com/gemini/answer/16417758); [Google AU blog (2025 offer)](https://blog.google/intl/en-au/products/explore-get-answers/gemini-for-students-australia/)
- This plan is for the Gemini app. It gives **no API access** for a website.

**Gemini API free tier** (not student-specific; aistudio.google.com/docs/pricing, fetched 2026-11-24)

**Vercel Hobby** (not a student programme; fetched 2026-11-24, page updated 2026-11-12)
- Free, with no billing cycle.
- Monthly allowances: 100 GB Fast Data Transfer, 1M function invocations, 4 active CPU-hours, 200 projects, 50 domains per project, 300 s maximum function duration.
- Exceeding a limit pauses the feature for up to 30 days.
- The free first-year domain is only for **paid** Pro.
- Source: [Vercel Hobby](https://vercel.com/docs/plans/hobby)

### Inferences
- A portfolio that may help land jobs is arguably "demonstrating software", which fits Azure's purpose wording. Selling services from it would not fit.
- The cleanest no-card path to a live custom-domain site with an AI feature:
  - a Student Pack domain (.me, .tech, or a Name.com extension);
  - hosting on GitHub Pages, Azure Static Web Apps (free) or Vercel Hobby;
  - a small serverless proxy (Azure Functions free tier or a Vercel function) calling the Gemini API free tier.
- Azure OpenAI drawing on the $100 credit is a possible alternative, but quota on student subscriptions is unreliable.

## Which offers give a free custom domain for a year or more, and what are renewal costs?

### Takeaway
Three Student Pack offers each give one free domain: Namecheap (.me, 1 yr), Name.com (one of 25+ extensions; duration not stated on the pack page), and get.tech (.tech, 1 yr). All are first year only. is-a.dev gives a free subdomain with no fixed expiry.

### Cited Findings
- Namecheap: .me for 1 year, plus SSL for 1 year. — [GitHub Student Pack](https://education.github.com/pack)
- .TECH: one standard .TECH domain free for 1 year. — [GitHub Student Pack](https://education.github.com/pack)
- Name.com: a free domain from 25+ extensions; the pack page gives no duration. — [GitHub Student Pack](https://education.github.com/pack)
- Azure Static Web Apps allows 2 custom domains free (always-free tier). This is hosting for a domain, not a domain registration. — [Azure for Students](https://azure.microsoft.com/en-us/free/students)
- Vercel's free first-year domain needs paid Pro, so it is not free. — [Vercel Hobby](https://vercel.com/docs/plans/hobby)
- is-a.dev: free subdomain, approved by PR. — [is-a-dev/register](https://github.com/is-a-dev/register)

### Inferences
- After year 1, the student pays the registrar's normal renewal price. Premium-ish TLDs such as .tech and .app can renew at a much higher price than registration. Check the price before choosing.
- A name you plan to keep long-term is safer on a TLD with low, stable renewal pricing.

### Gaps
- Renewal prices for .me (Namecheap), .tech (get.tech) and Name.com extensions were **not verified** on registrar pages in this session.
- The Name.com offer's duration was not confirmed on Name.com's own page.
- eu.org and js.org terms were not researched.

## Which give free AI model access usable from a deployed website, and what are the data-use terms?

### Takeaway
GitHub Models is retired (2026-07-30). The only free, production-callable option confirmed this session is the **Gemini API free tier**, which is not student-specific. Free-tier prompts **may be used to improve Google products**. The paid tier is not used for that. Azure OpenAI is usable but is paid from the $100 student credit, with no free quota, and student quota is reportedly unreliable. Copilot Student and the Google AI Plus student plan are not APIs for a website.

### Cited Findings
- GitHub Models: inference API retired for all customers on 2026-07-30. — [GitHub changelog](https://github.blog/changelog/2026-07-01-github-models-is-being-fully-retired-on-july-30-2026)
- Gemini API free-tier models include 3.8 Flash, 3.6 Flash, 3.5 Flash-Lite and 4 Hydrogen. "Used to improve our products": free tier Yes, paid tier No. — [Gemini API pricing](https://aistudio.google.com/docs/pricing)
- Azure OpenAI and Foundry are listed on the student page with no free quota. — [Azure for Students](https://azure.microsoft.com/en-us/free/students)
- Student quota problems and region limits reported in community Q&A. **UNVERIFIED** — [MS Q&A](https://learn.microsoft.com/en-us/answers/questions/2183197/azure-openai-with-azure-for-students)
- Copilot Student: completions and AI Credits inside GitHub Copilot. It is not an inference API for websites. — [GitHub Student Pack](https://education.github.com/pack)
- Google AI Plus student year: a Gemini app subscription that needs a payment method. — [Google blog](https://blog.google/innovation-and-ai/products/gemini-app/student-offer-google-ai/)
- Anthropic student API credits: 2025 programme existed; 2026 status **UNVERIFIED**. — [Anthropic Education](https://www.anthropic.com/education)

### Inferences
- For a public portfolio chatbot on the Gemini free tier, do not send personal or sensitive visitor data, because free-tier content may be used by Google.
- Keep the API key server-side in a serverless function, and add rate limiting, so free-tier quota is not drained by abuse.

### Gaps
- Gemini free-tier rate limits (RPM/RPD) were not on the pricing page. They are on a separate rate-limits page that was not fetched.
- Whether the Gemini free tier is available from Australia without a card was not confirmed.
- Not checked: Cloudflare Workers AI free allocation, OpenAI education offers, and Azure Foundry's non-OpenAI models' pricing on student subscriptions.

## What restrictions apply (non-commercial, academic use only, expiry on graduation)?

### Takeaway
- Azure for Students is limited to education, non-commercial research, and building or demoing software for those purposes. It needs full-time status. Services are decommissioned if you do not upgrade within 90 days of the credit or 12 months ending.
- Many Student Pack perks end when student status ends. Fixed-term perks (domains, Heroku) end at their term.
- Free first-year domains renew at full price.
- The Google AI student plan auto-bills after 12 months.

### Cited Findings
- Azure: "expressly for the support of education or teaching, noncommercial research, or efforts to design, develop, test, and demonstrate software applications for these purposes". Full-time students only. One subscription per person. Decommissioned without upgrade; 90-day upgrade window. — [Azure FAQ](https://learn.microsoft.com/en-us/azure/education-hub/azure-dev-tools-teaching/program-faq)
- Azure Dev Tools for Teaching software: students "in general" cannot sell apps made with it. — [Azure FAQ](https://learn.microsoft.com/en-us/azure/education-hub/azure-dev-tools-teaching/program-faq)
- Student Pack: many perks are "while you're a student" (GitHub Pro, Clerk, Doppler, Bootstrap Studio). Fixed terms: Namecheap 1 yr, .TECH 1 yr, Heroku 24 months, Appwrite 6 months. — [GitHub Student Pack](https://education.github.com/pack)
- Google AI Plus student year: payment method required. Auto-renews at $4.99 per month or the local equivalent unless cancelled. Claim by 31 Dec 2026. — [Google blog](https://blog.google/innovation-and-ai/products/gemini-app/student-offer-google-ai/)
- Google Cloud edu credits: valid 1 year after redemption. — [Google help](https://support.google.com/google-cloud-higher-ed/answer/10322773?hl=en)

### Inferences
- Before graduating, move the portfolio to hosting with no student dependency (GitHub Pages, Vercel Hobby, Cloudflare Pages). Budget for the domain renewal. Then nothing breaks when student status ends.
- Vercel Hobby is widely understood to be for non-commercial personal use. That wording was not on the fetched Hobby page, so it is **UNVERIFIED** here; check vercel.com/docs/limits/fair-use-guidelines.

### Gaps
- The GitHub Student Pack T&C (commercial use, what happens at re-verification) was not fetched.
- The is-a.dev terms on commercial use were not read.
- The full text of the Azure for Students offer terms (MS-AZR-0170P) was not fetched, so the eligibility footnote's exact wording is unconfirmed.
